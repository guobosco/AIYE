# 微信小程序安卓对齐清单

## 目标与边界

以 `android_aiye/app/src/main/java/com/example/PeiPei/` 当前源码为基准。
只修改小程序及确有必要的共享接口，不覆盖 Android、iOS 或已有运行数据。
使用 Taro 4.1.9、React 18、TypeScript、CSS Modules 和现有 FastAPI。
不另建 CloudBase 数据库，用户、收藏、发布和聊天均与 App 使用同一数据源。
不使用假数据掩盖接口故障，不假造实名认证、评价、订单或支付成功。

## 视觉交互设计

- 品牌色 `#E0115F`，深色 `#B00D4C`，奶油底色 `#F2F0EA`。
- 主文字 `#2F2730`，次文字 `#7B707A`，分割线 `#E7DFE3`。
- 首页白底；体验在服务前，默认体验；158dp 宽/200dp 高图片换算为 316/400rpx。
- 首页体验卡片不显示价格、时长；地点裁剪到市，正评分显示两位小数。
- 内容管理和搜索结果采用紧凑行布局；图片圆角 28rpx。
- 主操作高 100rpx、圆角 50rpx、描边 2rpx，与安卓 50dp 胶囊按钮匹配。
- 原生导航/原生四栏 tabBar 处理微信胶囊和安全区；固定操作栏留足底部安全区。
- 加载、错误重试、空数据、图片失败、未登录、提交中均独立处理。
- 页面切换保留 Tab 状态；下拉刷新、触底加载；操作反馈不使用宣传占位文案。

## 文件结构与选型

- `src/types/models.ts`：真实接口模型。
- `src/services/api.ts`：鉴权、错误处理、上传、分页、API 协议。
- `src/store/session.ts`：账号会话和登录门禁。
- `src/store/activity.ts`：按账号隔离的本地浏览/预约/日历。
- `src/utils/catalog.ts`：安卓分类和展示规则。
- `src/utils/booking.ts`：日期窗口、提前小时、时段计算。
- `src/hooks/useResource.ts`：资源状态/刷新。
- `src/components/UI/`：按钮、状态、行、头像、标签。
- `src/components/ItemCard/`：首页和紧凑行内容展示。
- `src/components/Detail/`：服务/体验共用详情骨架。
- 页面均包含 `index.config.ts`、`index.module.scss`、`index.tsx`。
- 原生 Taro 组件，不引入重型 UI 库；React 状态和会话事件即可。

## 发布条件

微信小程序必须使用可验证证书的 HTTPS 域名，并配置 request/uploadFile/socket 合法域名。
当前 App 的局域网 HTTP 地址只能用于本地联调，不能直接作为正式发布配置。
小程序已接入 `/auth/wechat/miniapp/login`，后端通过 `jscode2session` 换取身份；
正式使用须配置服务端小程序 AppID/Secret，不能复用 mobile OAuth 的 code。
正式支付必须有服务器创建订单和支付签名及回调校验；当前后端均未提供。
未满足上述条件时不宣称上线就绪或完整商业支付可用。
