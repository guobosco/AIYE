# 管理网站

本目录只包含管理网站前端，与 `backend/` 平级：

- `index.html`：页面入口。
- `admin.css`：页面样式。
- `admin.js`：页面交互和管理 API 请求。

不需要 npm 安装或构建。管理 API、认证和数据库操作仍由后端负责。

## 本地运行

按根目录 README 启动后端，然后访问 `http://127.0.0.1:8000/admin/`。
后端从本目录加载页面，样式和脚本 URL 保持为 `/static/admin/admin.css`
和 `/static/admin/admin.js`，管理 API 路径保持为 `/admin/api/*`。

后端默认查找同级 `admin_web/`。部署目录不同时，将环境变量
`LULU_ADMIN_WEB_DIR` 设置为本目录的绝对路径。
若不部署管理网站，后端 API 仍可启动，管理页面返回 404。

## 独立静态部署

可由 Nginx 等 Web 服务器单独托管本目录，不要求前端文件部署在后端机器上。
需要在同一个对外域名下配置：

- `/admin` 跳转到 `/admin/`。
- `/admin/api/*` 反向代理到后端，优先于 `/admin/` 静态页面规则匹配。
- `/admin/` 提供本目录页面，默认文档为 `index.html`。
- `/static/admin/*` 映射到本目录的对应文件，优先于其他 `/static/` 规则匹配。
- 其他 `/static/*` 反向代理到后端，用于头像和业务图片。

前端使用同源 API 请求。不要仅用独立端口的静态服务器打开页面，
否则 `/admin/api/*` 会请求到静态服务器而非后端。
管理员账号、密码和口令只配置在后端环境变量中，不写入前端文件。
